# NEXORA AI

### Personal AI Assistant built with Python

NEXORA AI is a Python-based personal AI assistant project designed to provide a simple, interactive command-line experience.

The project focuses on building the foundation of an AI assistant while practicing Python programming, logical thinking, user interaction, and project development.

---

## ✨ Features

- 🤖 Interactive AI assistant interface
- 💬 User-friendly command-line interaction
- 🧠 General information responses
- 🧮 Built-in calculator functionality
- 🎨 Clean terminal interface using Rich
- ⚡ Lightweight and easy to run
- 🐍 Built with Python

---

## 🛠️ Technologies Used

- Python
- Rich Library
- Git & GitHub
